監査と理由：[`docs/quality/presentation.md`](quality/presentation.md)　見本：`tools/figma-prototype/site`（`style.css` 末尾の「quality pass」の層、`app.js` の `RaceFx`／`paintFx`／`ResultCelebrate`／`Moment`／`CountUp`／`Reveal`）

分担はこれまでと同じ：**Claude＝見本とデータ／Codex＝Unity の画面・HUD・アニメーション・音・触覚**。今回はルール・経済・確率・レースの仕組みは**何も変わらない**。演出は既存の `HudSnapshot`（`unity/Assets/Muchi/Game/HudModel.cs`）と結果・ガチャのモデルを読むだけで、新しい API はない。

## 1. デザイントークン（1600×900 の基準解像度の px）

スマホの横向き（高さ 390pt）では **1px ≒ 0.43pt**。だから「読む文字は 16px 以上、本文は 20px 以上」が下限。

### 文字（Noto Sans CJK JP。数字は 700＋等幅）

| トークン | px | 使い方 |
|---|---|---|
| display | 112（ゴールの判子 150、カウント 180） | 結果の着順、ゴール、カウント |
| hero | 64 | 見せ場の見出し（差し切った！、カットイン 56） |
| title | 44 | 画面の題、馬の名前 |
| heading | 32 | パネルの見出し、大きい数字 |
| subhead | 24 | 一覧の題、主ボタン |
| body | 20 | 本文 |
| label | 18 | 見出し（シアン・字間 .12em）、タブ、チップ |
| caption | 16 | **読む文字の下限** |
| legal | 14 | 法定表記・脚注だけ |

### 余白・角丸・影・色

- 余白：4 / 8 / 12 / 16 / 24 / 32 / 44 / 64（パネルの内側 44、区切り 32）。
- 角丸：3（ピル）／4（パネル）／6（カード）／丸（ムチ・パッド）。新しい値は作らない。
- 影：elev-1＝上端 1px の光（白 6%）＋下に 0/10/28 黒 26%（パネル・カード）、elev-2＝0/16/40 黒 36%（トースト）、elev-3＝左に −24/0/64 黒 45%（右から出るシート）。入れ子のパネルは影なし。
- 着順の色：1 着 金 `#ffd34f`、2 着 銀 `#e4edf4`、3 着 銅 `#f0b07a`。**色だけにしない**（数字を必ず出す）。

### 動き

| トークン | ms | 緩急 |
|---|---|---|
| tap | 90 | 押した瞬間（沈み 0.97） |
| fast | 160 | 小さな切り替え |
| base | 280 | 画面のフェード、シート |
| slow | 480 | パネルの入り、ゲージの伸び、黒帯 |
| peak | 900 | 見せ場の入り |

緩急：out `cubic-bezier(.2,.7,.2,1)`（入り）、in `(.4,0,1,1)`（出）、inout `(.65,0,.35,1)`（帯・掃き）、spring `(.2,.9,.3,1.25)`（判子・瞬間）。
**メニューでは終わらない動きを置かない**（主ボタンの光は 2 回で止まる、光線は 9 秒で止まる）：電池と、ぼかしパネルの再描画のため。

## 2.5 ホーム（「1 回だけ言う」）

`quality/goals-flow` の目標の階段（`GoalLadderModel`）の上に、見た目の整理として：

| 要素 | 決まり |
|---|---|
| ① 目標の階段（左上） | 唯一の目標の面。段は 今日／はじめの10歩／今週／シーズン（＋ピン留めした馬の目標を 1 段として）。各段は自分の内容だけを書き、受け取れる段は金の点。**「受け取れる報酬があります」は最後の 1 行だけ**（金、右に「›」）で、押すと 目標（まとめて受け取る）。 |
| ② 相棒（主役） | 写真の馬そのものが主役。左下は名前の札（金の短い線、「あなたの相棒」、名前 52px、1 行：レア・脚質・馬場と距離・絆）だけ。 |
| ③ メニュー（右） | 厩舎・調教・スカウト・機能・イベントの 4 行。**目標の行は置かない**（階段と同じことを言うため）。 |
| ④ 「レースへ」 | 唯一の主ボタン（右下、hero、光は 2 回で止まる）。 |
| 次にやること | 枠ではなく**細い 1 行**（馬の下、「レースへ」の左）。サーバーの一覧（primary→chips）のうち、**ホームのほかの要素が言っていない最初の 1 件だけ**（ミッション・ログボ・ライバル・週替わり・支部・馬の目標・調教の回数・初勝利・最初のレースは出さない）。チップのボタンは出さない。 |
| 動画広告 | 大きなカードにしない。上の帯（階段と封筒の間）に小さな任意の入口「▶ 動画で無償コイン10枚」。受け取り済みは淡く。 |

## 3. 見せ場の振り付け

すべて**飛ばせる**（画面のどこかをタップ＝演出は最終状態へ、タップはボタンにも届く）。**動きを減らす（§41 `MotionPolicy`）**：動き・揺れ・紙片・光・スピード線・掃きは無し、最終状態を 120ms のフェードで。光は `FlashLimiter`（1 秒 3 回）を通す。触覚は設定の「振動」に従う。音は今回の見本には無い（下の「音」列は Unity で付けるきっかけ）。

### 3.1 レースのスタート（`HudSnapshot` を読むだけ）

| きっかけ | 見た目 | 音・触覚 |
|---|---|---|
| レース画面に入る | 上下の黒帯 72px（480ms、inout）。左から斜めの紺の札（コースの種類＝シアンの小見出し「ランク戦」、コース名 44px、金で「出走 12頭」） | 場内のざわめき（小） |
| `GateCountdownTicks` が 60→1（20Hz） | `ceil(ticks/20)` が 3・2・1 に変わるたびに中央に 180px の数字（1.5 倍→等倍で 160ms、0.9 秒で消える） | カウント音×3、触覚 8ms |
| `GateOpen` かつ `!Departed` | シアン 64px の「スタート」 | ゲートの音、触覚 20ms |
| `Departed` | 黒帯が開く、札が左へ抜ける（280ms） | 蹄音が立ち上がる |

チュートリアル（ゲート 1 秒）はカウント無し、既存の 1 行（「最後の直線。前に7頭。」）を使う。

### 3.2 最後の直線（残り 400m、チュートリアルは 300m）

| きっかけ | 見た目 | 音・触覚 |
|---|---|---|
| `RemainingM` が 400 を切る（1 回） | 中央にカットイン：上下にシアンの線の紺の帯、「残り 400 m」（シアン小見出し）＋「最後の直線」56px 斜体。右から入り（16%）、止まり、左へ抜ける（計 1.7 秒、inout） | どよめきが上がる、触覚 25ms |
| 直線の間ずっと | 黒帯 30px。周辺減光とスピード線の強さ `k = 0.35 + 0.4 × (400−残り)/400 + (Spurt ? 0.25 : 0)`（0.05 刻み）。HUD は**押すもの以外が引く**：ミニマップ・コース名のバナー・応援・注記は 0、中断／フォト・かんたん操作の札は 40%。距離・順位・スタミナ・ムチ・手綱・内外はそのまま | 蹄音と歓声が k に合わせて大きく |
| `WhipsLeft` が減る | 減光が 1 回脈打つ（340ms） | ムチの打音 |
| `Rank` が上がる | 順位の札が 1.14 倍＋金の縁の光から戻る（600ms） | 短い上昇音 |

HUD の配置と入力は race-play の担当。ここでは**重ね物と不透明度だけ**。

### 3.3 ゴール

| きっかけ | 見た目 | 音・触覚 |
|---|---|---|
| `Finished`（自分の馬、1 回） | 減光・線が消える。中央に判子：「ゴール」24px（字間 .4em）＋着順 150px（1 着 金・2 着 銀・3 着 銅・ほか白）、1.8 倍→等倍（600ms、spring）。3 着以内は光 1 回（1 着は金、2・3 着は白っぽい） | 歓声、1 着は触覚 30-50-30-50-90 |
| レース終了＋1.1 秒（従来どおり） | 結果画面へ | — |

### 3.4 結果の祝い方（着順で 3 段階）

| 着順 | 背景 | パネル |
|---|---|---|
| 1 着 | 金の光線（画面右、直径 1300、0.6→1 倍で 900ms、−24°→0° を 9 秒）＋金とシアンの紙片 26 枚（2.2〜3.2 秒で落ちる、1 回）＋金の光 1 回 | 着順「1着」が 1.6 倍・ぼかしから spring で入り、金の光沢が左へ 1 回流れる。見出しの線が金。数字（タイム→コイン→シーズン pt）が 120ms ずつ遅れて下から現れ、コインと pt は数え上がる |
| 2・3 着 | 銀の静かな光線（直径 1100） | 着順が銀／銅で spring |
| 4 着以下 | なし（静かに。敗因とヒントが主役） | 数字の入りだけ |

おまけのボタン（写真を撮る・マイリプレイに残す・リプレイを共有）は下に 1 列、`quiet`。主ボタン「もう一度」だけが目立つ。

**昇級の瞬間**：このレースでシーズン pt がクラスの昇級ライン（`promotePoints`）を**またいだ**とき、結果が出て 1.5 秒後に `Moment`（小見出し「クラス C」、見出し「昇級ラインに到達」、一言「シーズンの終わりに昇級します」）。数字はサーバーの値のまま。

初レースの勝利（チュートリアル）も 1 着と同じ祝い方（見出し「差し切った！」に金の光沢）。

### 3.5 スカウトのめくり（`GachaRevealModel` の順・結果は変えない）

| レア | 溜め | めくれる瞬間 |
|---|---|---|
| N・R | 0.38 秒（従来） | 裏返り（600ms） |
| SR | 1.0 秒：後ろにシアンの光線、裏面が暗→明るく（0.96→1.04 倍）、触覚 10-80-10 | 光の輪が広がる（700ms）、シアンの光 1 回、触覚 40 |
| SSR | 1.5 秒：後ろに金の光線、裏面が明るく、最後の 0.5 秒に小さく揺れる、触覚 10-80-10-80-10 | 金の輪、金の光 1 回、触覚 40-40-80 |

カードを押せば溜めを飛ばしてすぐめくれる。「すべてめくる」はそのまま。動きを減らす：溜め 0 秒、光線は止まって表示、輪・光・揺れなし。一覧では一番良い馬が SR 以上なら後ろに光線。

## 4. 見本との対応（実装の手がかり）

| 見本 | Unity |
|---|---|
| `style.css` 末尾の `:root`（`--fs-*`・`--sp-*`・`--r-*`・`--elev-*`・`--dur-*`・`--ease-*`・`--place-*`） | テーマの定数（ScriptableObject か static class）。数値は同じ |
| `RaceFx`／`paintFx`（`app.js`） | レース画面の重ね物。`HudModel.Build` の `HudSnapshot` を毎フレーム読む。状態（カウント済み・直線済み・ゴール済み・前の順位・前のムチ数）は画面側に持つ |
| `ResultCelebrate`・`CountUp`・`Moment` | 結果画面と共有の「瞬間」プレハブ |
| `Reveal` の `rare` 分岐 | めくりの溜めとバースト |
| `.fx-skip` | 画面タップで全部のアニメを最終フレームへ（入力は通す） |
| `html[data-reduce-motion]` | `AccessibilityModel`／`MotionPolicy` |
