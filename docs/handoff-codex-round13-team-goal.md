## 2. 画面の構成（「ムチ一閃」のトーン）

見本と同じ1600×900の構図。**写真の背景（`Art/home-paddock`）を全面に、紺の半透明パネルは2枚、主ボタン（斜めのシアン »）は1つ**。小見出しはシアンの線＋字間を空けたシアン。

- 上の帯：`支部　/　共同目標`、サブ「今週の目標を支部のみんなで · 進むのは確定したレース結果だけ」、通貨 HUD、EN。
- 左パネル（今週の目標）
  - 小見出し「今週の共同目標」。目標の文 `Week.Label`（サーバーが作る。英語ではサーバーが英語で返す）を大きく。支部名 `View.TeamName` は小さく（**プレイヤーが付けた名前：翻訳しない・ローマ字にしない**）。右に `EndsText`（「12月21日 4:00 締め」）。`Closing` が true の間は「集計中」の表示にしてよい。
  - 進み具合の数字（金・大）と「目標 60レース」。
  - **段のバー**：`ProgressFraction` で塗る（シアンのグラデーション）。`Milestones` の各 `Position`（0〜1）に縦の印。届いた段（`Reached`）は金。印の下に `TierText`（「2段目」）・`TargetText`・`RewardText`（金）。最後の段のラベルは右寄せ（はみ出さない）。
  - `NextText`（「次の段まで あと15レース」／「最後の段に到達しました」）。
  - 区切り線の下に小見出し「あなたの貢献」：`MyText` の数字部分、`QualifiedText`（対象ならシアン）、`TodayText` と細いゲージ（`MyToday / DailyCap`）、上限に届いたら `CappedText`。
- 右パネル（貢献の多い支部員）：`Contributors`（最大5人）。順位（シアン）・名前（`Name`、**翻訳しない**）・`CountText`（金、右寄せ）。自分の行（`Mine`）は左端にシアンの線。下に `TeamGoalModel.RulesText` を小さく必ず表示（1日の上限・無償・抽選なし）。
- 主ボタン「レースに出て貢献する »」→ ランク戦のロビー。**貢献を増やすボタン・課金への導線は置かない**（進むのは確定したレース結果だけ。「倍」「今だけ」「お得」は使わない）。
- 支部に入っていない：`EmptyText`（「支部に入ると共同目標に参加できます」）と支部を探す導線。オフライン：`UxText.Offline`。

## 3. 段のバーと到達の演出（お願いしたいこと）

| 場面 | 動き | 長さ |
|---|---|---|
| 画面を開いた時 | バーが 0 から `ProgressFraction` まで伸びる（ease-out）。数字もカウントアップ | 0.6秒 |
| 前に見た時より段が増えていた | 印が金に変わる瞬間に小さな光の輪、ラベルが一度だけ跳ねる | 0.4秒 |
| 最後の段まで届いている | バー全体に金の細い光が1回走る | 0.8秒 |

- 前に見た進み具合は端末に覚える（例：`muchi.teamgoal.lastProgress`）。サーバーの値が下がることがある（隔離・削除された人の分が消える）ので、その時は演出なしで下げる。
- 演出はタップで飛ばせること。

## 4. 週の結果シート

`TeamGoalModel.Result` が null でない時（週が締まった後、その週に初めて開いた時）に、右から出るシートで見せる。閉じたら `DismissResult()`（端末に週を記録し、同じ週は二度出さない）。

- 小見出し「週の結果」、タイトル「先週の共同目標」、`Label`、`TierText`（届いた段は金・大）、進み具合、`RewardText`（金）、`MineText`（受け取った／準備中／対象外の理由）、上位の貢献者（名前は翻訳しない）。
- 受け取った時：コインのアイコンが HUD の無償コインへ飛ぶ演出（1回だけ、0.6秒）。**ガチャのような抽選・めくりの演出は使わない**（報酬は決まっている）。
- 段に届かなかった週も責めない文（`MineText`：「次の週も支部のみんなで挑戦しましょう」）。

## 5. 支部フィードの goal 行

`FeedRow.IsGoal` の行は支部の行（投稿者なし）。`Line`（「共同目標「支部で合計60レース」が2段目に到達！」）をシアンで、左に小さな旗のアイコン（新しいアセットキー案：`ui/team_goal_flag`）。「非表示」「報告」は出さない（ミュートで消えない・報告できない）。応援スタンプのリアクションは表示してよい（付けても通知は無い）。行をタップしたら共同目標の画面へ。

## 6. 音・触覚

- 段に届いた演出：短い上昇音（既存の「ミッション達成」と同系統）＋軽い触覚1回。結果シートの受け取り：コインの音。
- push `team_goal`（「支部の共同目標が{n}段目に到達しました」）は他の支部員に届く。通知から開いた時は共同目標の画面へ。

## 7. 描いてほしい物の一覧

1. 共同目標の画面（日本語・英語の2枚）：左パネル（目標・段のバー・あなたの貢献）、右パネル（貢献の多い支部員・ルール）、主ボタン1つ。
2. 段のバーの部品（溝・塗り・印・届いた印・ラベル3段）と到達の演出（§3）。
3. 週の結果シート（届いた／届かなかった／対象外の3状態）。
4. 支部フィードの goal 行（旗のアイコン `ui/team_goal_flag`）。
5. 支部に入っていない時・オフラインの空表示。

英語は文が長くなるので、ラベルは縮小（見本の `fitText` と同じく最小 66%）で1行に収める。名前（支部名・支部員名）は日本語のまま表示する。
