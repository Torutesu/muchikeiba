## 2. 支部の画面の切り替え

今の支部の画面（左＝フィード、右＝スタンプのパレット、右下＝塗りの CTA）の**右のパネルだけ**を「スタンプ」⇔「定型チャット」で切り替える。見本では右のパネル（x=996, y=134, 568×560）の右上に線のボタン（小、204×50）。左のフィードはそのまま（スタンプ・レース・共同目標・定型チャットが1本の時系列）。画面を増やさない。
- **文字の入力欄はどこにも置かない**（キーボードを出さない）。e2e は `input / textarea / contenteditable` が 0 個であることを確かめている。

## 3. 定型文の選び方（`QuickChatModel`）

上から：
1. **小さなシアンのラベル**「定型チャット」（`Kicker`）、その下に灰色の小さな字で `今日 3 / 30`（`Picker.PostsToday` / `PostsPerDay`）。
2. **分類のタブ**（`Tabs`、5つ固定：あいさつ・応援・支部・レース・さそう）。横いっぱいに等分、字間を広く、選んだタブは下に 3px のシアンの線。最後に選んだタブは端末に覚えている（`KeyLastCategory`）。
3. **定型文の一覧**（`Phrases`）。1行1文の紺の板（不透明度 .72、細い線）。文はサーバーの `Preview`（選ぶ前は空欄）。空欄は**下線だけの空の箱**（見本の `.qc-blank`。「〇〇」などの文字は入れない。モデルの `Fill` は `＿＿` を返すので、ビューでは箱に置き換えてよい）。選んだ文は左に 3px のシアンの線＋薄いシアンの地。`Available == false`（選べる値が無い、例：タイムアタックの記録が無い）は灰色にして、下に小さく `DisabledReason`（「選べるものがまだありません（タイムアタック）」）。押すとトーストで同じ文。
4. **空欄の値**（`Slots`、選んだ文のスロットごと）：シアンの小さなラベル（「コース」「馬」…）＋値のチップ（斜めの紺の板、選んだら塗りのシアンに紺の字）。値は `Options`（サーバーが受け付ける物だけ：自分の現役の馬・最近のレース・タイムアタックの記録・出ているカップ・ブロックの関係にない仲間・コース）。**選べる値が1つだけなら最初から選ばれている**（モデルが選ぶ）。コースは8つあるので折り返す（見本は2〜3行）。
5. 選んだ文は一覧の中でそのまま埋まって見える（別の見本欄は作らない。見本も同じ）。

## 4. フィードの行（`Rows`、`kind: "qchat"`）

§18 の行と同じ形（細い線で区切る・上に字間の広い灰色のメタ行）。
- メタ行：`名前　·　5分前`。自分の行は「あなた」でシアン。**私の名前を出した行**（`MentionsMe`）は行の左に 3px のシアンの線＋メタ行の最後に「　·　あなたに」。
- 本文：定型文（白・太字・21px 相当）。**値はシアン**（見本の `.qc-val`）。カップ名は主催者が付けた名前のまま（英語でも訳さない、§42 と同じ `keep-ja`）。
- 抜けた人の行（`Anon`）：名前は「元メンバー」（英語は「Former member」、サーバーが入れる）。メタ行を暗い灰色に。**非表示（ミュート）のリンクは出さない**（相手がいない）、報告だけ。
- 下：§18 と同じ応援の数のチップ・「「ナイス！」で応援 »」（自分以外の行）・「非表示」「報告」の文字リンク。
- ブロックは**両方向**（サーバーが隠す）。端末のミュート（`TeamFeedModel.KeyMuted`）でもすぐ隠れる。

## 5. 送る

右下の塗りの CTA（今までのスタンプの CTA と同じ位置・形、斜めのシアンに »）。文言は「この文を送る」。押せない時は `SendDisabledReason` をそのまま CTA に出して灰色に：オフライン・支部なし・削除の予約中・今日の上限・「文を選んでください」・「空欄を選んでください」・「あと15秒で送れます」（250ms ごとに数え直す。**カウントダウンの演出はしない**、数字が変わるだけ）。
- 送れたら：フィードの一番上に自分の行が入り、選んだ文と値は解除（`SelectedPhraseId == null`）。音は §18 のスタンプを送った時と同じ短い音でよい。
- 失敗の文：`RATE_LIMITED` →「定型チャットは15秒に1回、1日30回までです。同じ文は続けて送れません」、`NOT_ELIGIBLE` →「この内容では送れません」（ブロックの関係などの理由は言わない）。トーストで出す。
- **自動の再送はしない**（投稿は冪等ではない）。

## 6. 英語・文字の大きさ・動き

- 定型文・値・「元メンバー」はサーバーが**読む人の言語で**返す（`Text` / `Preview` / `QuickChatOption.Text`）。ビューでは `Loc.T` を**通さない**でそのまま出す（カタカナの名前は他の名前と同じくクライアントのローマ字化に任せてよい：見本はフィード・チップの名前を他の画面と同じように扱う。カップ名だけは `keep-ja`）。モデルの短い文言（タブ・スロット名・送れない理由）は `Loc.T(label)`。
- 文字の大きさ（§41）：タブ・定型文・値のチップ・行の本文とメタ行は大きくなる（見本は `.qc-scale`、a11y-flow で最大サイズの日英を確認）。一覧と値の欄は縦にスクロールする。英語で長い文（"Glad to be racing with you all!"）は折り返す（1行に詰めない）。
- 動きを減らす（§41）：選んだ時のハイライトの移動・行の追加のアニメーションは減らす設定で無し。

## 7. 通報（Round 17 の §47 との続き）

この版は §18 の通報（`POST /v1/teams/me/feed/:seq/report`）を使う。各行に `FeedQuickChat.ReportKind / ReportTeamId / ReportSeq`（`{kind:"team_feed", teamId, seq}`）が入っているので、§47 の通報・ブロック管理（Round 17）がマージされたら、その通報の画面にこの対象を渡すだけにしてある（サーバー側の受け口は §47 の担当が作る）。ブロックの一覧は1つ（§18 のミュート＝§47 のブロック管理の一覧）。

## 8. アクティビティ

`qchat_mention`（ラベル「支部」、アイコン `chat`）は §40 の一覧の新しい種類。文はサーバー（「{name}さんが支部のチャットであなたに声をかけました」／まとめて「支部のチャットで{n}件の声がかかりました」）。押すと支部の画面（`team_feed`）。プッシュは出ない。

## 9. 描かないもの

- 文字を打つ欄・絵文字の選択・自由なスタンプの組み合わせ。
- 「既読」「入力中」の表示（情報を増やさない）。
- 定型文の購入・解放（すべて最初から使える。ショップへの導線を置かない）。
