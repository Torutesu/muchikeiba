# 01. 市場調査（2026年11月時点）

公営競技（競馬・競艇・競輪・オートレース）を題材にしたゲームアプリの調査結果。

## 1. きっかけ：VS BOAT（3D競艇オンライン対戦）

| 項目 | 内容 |
|---|---|
| 開発 | soma anraku（会社表記なし。個人か少人数とみられる） |
| リリース | 2026年10月7日 v1.0 → 10月25日 v2.0（シーズン制）。約1か月で12回更新 |
| 実績 | App Store スポーツ無料1位、評価4.5（1,310件）、年齢区分9+、容量1.5GB |
| ゲーム | 最大6人リアルタイム対戦（空き枠はCPU）、3周、左手レバー＋右手ハンドル、大時計スタートとフライング、日本時間と連動する空とナイター |
| 課金 | 勝負服・船体のガチャ（ダブりは強化券）、初回10連無料、天井カウンター、コイン ¥160〜¥10,000（8段階）、シーズンパス 月¥1,000 |
| 継続 | 月次クラスランキング、支部（チーム戦）、称号、タイムアタック、リプレイとゴースト、フレンド部屋 |

### 伸びた理由
1. 本物と同じ操作（スタートタイミング＝実力差）
2. 登録不要・CPU補完ですぐ遊べる
3. ガチャで見た目と強さの両方が手に入る
4. 毎週のような更新がレビュー評価になっている
5. 「競艇 ゲーム」で検索したときに3D対戦の競合がいなかった

### 弱点（レビューより）
- ガチャで強化したモーターとランク戦が混ざっていることへの不満（＝課金で勝てる問題）
- 通信対戦の重さ・切断
- インコースが弱いなどのバランス

## 3. 競合ゲーム

| 領域 | 既存ゲーム | 3Dリアルタイム対戦 |
|---|---|---|
| 競艇 | VS BOAT、競争艇スプラッシュ6（ZenRock、広告型の育成シミュ） | VS BOATが先行 |
| 競馬 | ウマ娘、ダビスタ、ダービーインパクト、ギャロップレーサー、リアル競馬ジョッキーほか | 騎手として操作する本格対戦は見当たらない |
| 競輪 | 競争転ピストレーサ（ZenRock、2D育成シミュ） | なし |
| オートレース | 競争単ゼロハンレーサー（ZenRock、2026年9月） | なし |

## 4. 結論
- 競艇に二番手で入るより、空いている所を取る。
- 当初は競輪（競合ゼロ・伸び率最大・ライン＝チーム戦）を本命としたが、
  **市場とファン数が最大で、ガチャ（馬そのもの）と配合のやり込みに相性が良い競馬から始める**ことにした。
- 勝負する所は「騎手として乗る × リアルタイム対戦」だけ。育成・オーナー視点では戦わない。
- 競馬で作った土台（リアルタイム対戦・ガチャ・シーズン制）は競輪・オートレースに流用できる。
