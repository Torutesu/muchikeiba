# 02. ゲームコンセプト

## タイトル
- 仮タイトル：**『ムチ一閃』**（副題：3D競馬ジョッキー オンライン対戦）
- キャッチコピー：最後の直線、ムチ一発で差し切れ。
- 候補：『差し切れ！』（炎上リスク最小。ただし一般的な言い回しで商標としては弱い）、『鞍上』、『JOCKEY VS』
- **要判断**：「ムチ」は動物福祉の観点で批判されうる。最終決定前にJ-PlatPatで区分9・28・41を確認する。

## 概要
- iOS / Android（Unity）、横画面、両手操作
- 最大12頭のリアルタイム対戦（空き枠はCPU）、1レース約90秒

## ゲームの柱
1. **乗って勝つ（実力）**：ゲートの出、位置取り、折り合いで脚をためて、直線でムチ。ランク戦は能力に上限をかけ、腕で勝てる設計。
2. **馬を集める（ガチャ）**：ガチャで出るのは馬そのもの。脚質・距離適性・毛色・固有スキルで個性。
3. **血をつなぐ（やり込み）**：引退馬で配合し、自分だけの名馬を生産。

## コアループ
レース → 報酬 → 集める（ガチャ） → 育てる（覚醒・配合） → 昇級（月次クラス戦） → レース

- 毎日：ログボ、デイリーミッション、数レース
- 毎月：シーズン戦で昇級・降級、シーズンパス更新
- 長期：配合で血統を広げる

## レースの中身

| 局面 | 操作 | 上手い人がやること |
|---|---|---|
| ゲート | スタートをタップ | ゲートが開く瞬間に合わせて好位を取る |
| 序盤 | 内へ・外へ | 脚質に合う位置へ。外を回りすぎない |
| 道中 | 手綱で抑える | 折り合いを保ち、前の馬の後ろで脚をためる |
| 3〜4コーナー | 進路を選ぶ | 前が壊れる瞬間を読んで、外に出すか内を突くか |
| 直線 | ムチ（最大6回） | 連打せず、伸びるタイミングで入れて差し切る |

## 機能のロードマップ

| 区分 | v1（リリース時） | リリース後3か月 | その先 |
|---|---|---|---|
| レース | 芝3コース・12頭対戦・CPU補完 | ダート・ナイター・重馬場 | 海外風の架空競馬場 |
| モード | ランク戦・フレンド部屋 | タイムアタック・ゴースト | 大会・観戦モード |
| 馬 | ガチャ・覚醒・脚質と適性 | 固有スキルの追加 | 季節限定の馬 |
| 育成 | 配合・血統表（5代） | ニックス・隔世遺伝 | 種牡馬の貸し借り |
| ソーシャル | フレンド・戦績・称号 | 支部（チーム戦） | 支部対抗シーズン |
| 運営 | 月次シーズン・ログボ | イベントレース | AI実況の多様化 |
| 課金 | ガチャ・パス・コイン | 勝負服の直販 | 厩舎の飾り |

**v1に予想・賭けモードは入れない**（年齢区分と法務のため）。

## 画面（モックアップ作成済み）
① ホーム ② レース中 ③ ガチャ結果 ④ 厩舎・配合 ⑤ 初回レース（チュートリアル） ⑥ 相棒の命名 ⑦ ショップ ⑧ 初回購入時の年齢確認

見た目（UI・3D演出）はCodexで実装する。本リポジトリのロジックはUIから呼び出せるAPIとして提供する。

## AIで作るもの／人が詰めるもの

| AIで作る | 人が詰める |
|---|---|
| Unity C# の実装全般 | 馬の走りのモーション（市販素材＋調整） |
| ガチャ用の馬・騎手イラスト、勝負服の柄 | 12人同時対戦の通信の安定 |
| 画像から3Dの小物・背景 | ムチを入れた瞬間の手応え |
| AI実況（音声合成） | 課金とランク戦のバランス判断 |
| 数千レースの自動対戦でバランス検証 | AI生成物の類似チェックと法務 |
| ストア画像・広告動画 | 毎週アップデートの運営 |
