# 04. 課金設計とオンボーディング

## 課金の基本方針
**腕で勝つ。課金で集めて、育てて、飾る。**
ランク戦は能力に上限があり、課金で勝ちは買えない。だから無課金も残り、対戦が過疎らない。

### 最初の課金のきっかけ
1. 初回購入ボーナス：どのパックも初回は2倍
2. スターターパック ¥480（1回限り）：SR以上確定チケット＋限定勝負服＋有償300コイン。初めてランク戦で負けた後に表示
3. シーズンパスは即時報酬つき
4. 課金の理由を「強さ」以外に（勝負服・配合枠・厩舎）

### やらないこと
- スタミナ制で対戦回数を縛る
- 有償で能力上限を突破し、ランク戦で有利にする
- 偽の残り時間・偽の在庫などで急かす
- 「確定」と誤解させる演出、告知文で確率を語る
- レース中の全画面広告
- 有償アイテムの譲渡・売買

### 追う数字
翌日・7日後・30日後の継続率、初回課金までの日数と課金率、ARPDAU、シーズンパス継続率、無課金のランク戦勝率、未使用の有償コイン残高（資金決済法ライン）。目標値はプロトタイプ後に決める。

## オンボーディング
**起動して20秒で、もう走っている。**
原則：説明は読ませず体験させる／1画面で教えることは1つ／最初の負けはできるだけ後に／お願いは勝った直後に。

### 最初の6分
| 時刻 | ステップ | 内容 |

| 0:00 | 起動 | 規約同意は1タップ。登録も年齢入力もしない |
| 0:20 | いきなり本番 | 最後の直線から始まる演出レース。操作はムチだけ。差し切って勝つ |

### その他
- 最初のダウンロードは小さく。競馬場・馬のデータは裏で取得（VS BOATは1.5GB）
- 初めての対戦は初心者同士＋CPUで勝率を調整
- 許可・登録のお願いは1回ずつ：通知→初勝利直後、トラッキング→その後、引き継ぎ登録→初課金か3日目
- 初回購入時に年齢確認（生年月・年齢別月額上限・保護者同意）
