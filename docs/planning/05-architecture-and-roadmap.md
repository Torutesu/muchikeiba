# 05. 技術構成・インフラ費・ロードマップ

## 方針：常時動くサーバーを持たない
- **レース計算は12台の端末で行う**（決定論ロックステップ）。サーバーは操作の中継と結果の照合だけ。
- **不正は照合で防ぐ**：ゴール時に全員の結果ハッシュを突き合わせ、不一致・通報・抜き取り対象だけサーバーで再計算。
- **「部屋」単位で分ける**：1レース＝1部屋、プレイヤー1人＝1部屋。ユーザーが10倍になっても部屋が増えるだけ。

## 技術スタック

| 領域 | 採用 | コストと規模の考え方 |
|---|---|---|
| ゲーム本体 | Unity 6（URP）・C# | 計算はできるだけ端末側 |
| レース計算 | 自前C#エンジン（1次元・固定小数点） | 物理エンジン不要で軽い。端末とサーバーで同じコード |
| 対戦の中継 | Cloudflare Durable Objects | 1レース＝1部屋。入力を中継するだけ |
| プレイヤーデータ | Durable Objects（1人＝1部屋） | 財布と所持品を1人ずつ持つので自然に分散 |
| API・課金検証 | Cloudflare Workers | 使った分だけ課金。サーバー管理なし |
| 配信データ | Cloudflare R2＋CDN | 転送料（エグレス）無料。初回DLを小さく |
| 認証・分析・通知 | Firebase（無料の部品だけ） | 匿名認証・Analytics・Crashlytics・FCM |
| 再計算（検証） | .NET（同じC#エンジン）・0台まで縮小 | 不一致や抜き取りのときだけ動く |

代替案：対戦はPhoton Fusion 2（100 CCUまで無料）／Netcode for GameObjects、バックエンドはNakama・PlayFab・Firebase単体。

### 確認できた料金（2026年11月時点・要再確認）
- Durable Objects：有料プランが必要。リクエストは月100万件まで含まれ、超過は100万件あたり0.15ドル。WebSocket休止中は時間課金なし
- Firebase Auth：匿名・メール・SNSは月49,999 MAUまで無料
- Photon Fusion：100 CCUまで無料

## インフラ費を抑える工夫
1. サーバーで物理計算しない（各端末で計算、サーバーは中継）
2. 待っている間は課金されない（WebSocket休止）
3. ランキングは数分おきに集計してCDNで配る
4. 画像・データは転送料無料のR2＋CDN。マスターデータは差分配信
5. AI実況は作り置き（定型フレーズ共通、馬名音声は命名時に1回生成）
6. 操作ログは短期保存、怪しいレースだけ長期保存

月の費用 ≒ レース数 × [1レース単価] ＋ 月間ユーザー数 × [1人単価]（プロトで実測）

## ゲームバランスの骨子
- ランク戦では馬の総合値をクラス上限に圧縮（正規化）。脚質・適性の「形」は残す
- 毎週見る数字：脚質別・枠順別・課金額帯別の勝率
- 調整つまみ（初期値・調整前提）：前の馬の真後ろで脚の消費−20%、外を回ると距離が延びる、折り合いが悪いと消費＋30%、ムチ最大6回（連打は効果減）、スタート反応0.2秒以内で加速、直線は残り脚が多いほど伸びる
- 数値はサーバー設定値で持ち、アプリ更新なしで調整
- マッチング：レート制（Glicko-2）、初心者同士＋CPU、15秒で揃わなければCPU補完

## ロードマップ（約6か月でリリース）

| フェーズ | 期間 | 内容 | 合格ライン | ダメなら |
|---|---|---|---|---|
| 0 プロトタイプ | 4週 | 1人で走る操作感 | 試遊者が「もう1回」と言う | 操作を作り直す |
| 1 縦切り版 | 8週 | 12頭対戦・1競馬場・CPU・AI実況 | 切断率 [目標]% 以下 | 通信方式を見直す |
| 2 MVP | 8週 | ガチャ・配合・課金・法務・オンボーディング | 弁護士レビュー済み、確率表示テスト合格 | リリースしない |
| 3 クローズドβ | 4週 | 負荷試験・ストア申請 | 翌日継続率・初回課金率 [目標] | オンボーディング改善 |
| 4 運営 | 毎週 | 1か月でシーズン制 | 無課金と課金者の勝率差 [目標] 以内 | 正規化の上限調整 |

体制の目安：エンジニア2（AI併用）・3D/モーション1・企画兼運営1。

## リスク

| リスク | 重さ | 対策 |
|---|---|---|
| 馬の走りが不自然 | 高 | 市販モーション＋共通体型。差は毛色と装具で |
| 12人対戦のラグ・切断 | 高 | 縦切り版で先に検証。自動再接続とCPU引き継ぎ |
| 端末ごとに結果がズレる | 高 | 固定小数点・物理エンジン不使用。結果照合、ズレたら再計算 |
| 課金で勝てると思われる | 中 | ランク戦は能力を正規化 |
| 法務・表示のミス | 中 | 確率表示の自動生成、弁護士レビュー |
| 大手の参入 | 中 | 先に出して毎週更新 |
| 動物福祉での批判 | 低 | ムチ回数制限、故障は描かない |
