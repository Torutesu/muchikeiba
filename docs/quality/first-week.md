## 1. 監査のやり方

- `bash tools/figma-prototype/build.sh` のあと、本物のサーバーの規則（`logic.js`）と WASM で動く `index.html` を Playwright（844×390）で遊んだ。
- **毎日まじめに遊ぶ新規プレイヤー**を1日ずつ再現（スクラッチパッドの `q2wk-week.cjs`）：その日の起動（bootstrap → ホーム＝ログボ自動受け取り）→ ランク戦3本 → 相棒を2回調教 → 目標をまとめて受け取り → ホーム。日ごとに朝と夜のホーム、目標の画面を撮った（`q2wk-before-d{1..7}-*.png`、`q2wk-before-week.json`）。従来の `?demo=day1|day3|day7`（ログボと結果の精算だけ）も撮った。
- 1日の所要：FTUE を除いて 3戦（約90秒×3）＋調教2回（各約10秒）＋受け取り ≒ **6〜8分**。

## 3. 弱いところ（効いている順）と、なぜ継続・課金に効くか

1. **明日の楽しみが見えない**（1〜6日目）：明日の報酬・明日開く機能は全部データにある（初心者ログボ7日・`unlocks` の `days`）のに、ホームはそれを言わない。モバイルの強いゲームは「今日の終わりに明日の山を事実で見せる」ことで D1→D2 を作る（カウントダウン・煽りではなく）。ここが一番安く一番効く。
2. **相棒が育って見えない**：1週間で唯一「自分だけのもの」が積み上がるのが相棒の調教（7日で +50、新馬→成長期）。品質パス1で馬カードは作ったが、毎日見るホームには出ていなかった。毎日1回見える数字が動くことが、作業（デイリー消化）と育成の違い。
3. **次の一歩が1タップで行けない**：はじめの10歩の段は何をするかは言うが、押すと目標の画面に行くだけ。新規プレイヤーは「勝負服」「飼い葉」がどこにあるか知らない。
4. **2〜3日目のノイズ**：3日目は開いた瞬間に全画面の案内、内部 ID のトースト。開く機能が毎日1行ずつ「次にやること」に出て、前日の予告が無い。
5. （判断が要る）**7日目の崖**・**はじめの10歩の社交の段**（フレンド・支部をやらない人は10連券に届かない）・**通知の文言**（§5）。

ジャンルの強いゲームが一般にうまくやっていること（特定の作品の名前・画面・仕組みは真似しない）：1日の終わりに「明日」を1行で予告する／育てている対象の変化を毎日の入口に置く／やることの行き先を1タップにする／初日〜3日目は割り込みを最小にし、割り込むなら勝った後など気分の良い瞬間に。

## 4. 作ったもの（上位3つ＋ノイズの整理）

### 4.4 ノイズの整理
- **3日目の引き継ぎ登録の案内**（`AccountLinkPrompt`）：その日の最初の画面にしない。3日目はレース結果を閉じた後に出し、4日目以降はホームでも出す（1回だけ・FTUE 中なし・セッションに1つの規則はそのまま）。
- **ログボのトーストの内部 ID**：`costume_login` に表示名（`products.json` の `itemLabels`、英語は `locale-en.json`）。`training_apple` も同じ表に。
- 「明日」の行は、今日のセットが終わった後だけ今日の段に出す（それまでは今日の目標が主役）。今日の段の「5/5」は終わった後は出さない。

### 4.5 守ったこと
- **経済**：付与・消費・額・時期は1つも変えていない（読むだけの項目と表示だけ）。E1〜E20 は変わらない（`npm run economy`）。
- 煽り・カウントダウンなし（「明日 4:00」は時刻）、ショップ・購入への誘導なし（行き先は固定、テストで確認）。§58 のプロンプト表は変えていない（引き継ぎの案内の「いつ」だけ）。FTUE は触っていない。
- 英語：`ui-en.json`（Unity・プロトタイプ共通）、`proto-en.json`、`locale-en.json`。文字「特大」でもはみ出しなし（e2e）。

## 5. オーナーに決めてほしいこと

1. **7日目の崖**：初心者ログボ（繁殖牝馬・SR以上券）の後、8日目からは「無償コイン50枚」の7日周期。2週目の山（はじめの10歩の10連券・最初の昇級＝月末）まで「明日」が弱い。案：(a) はじめの10歩の最後（10連券）を2週目の明確な目標として「明日」の行に出す（表示だけ）、(b) 8〜14日目に小さな初心者2週目のログボ（**E1 が 64.2/65 で余裕が無いので経済を回してから**）。
2. **はじめの10歩の社交の段**：6段目「フレンドを追加」・7段目「支部に入る」を終えないと10連券（10段目）に届かない（段は順番に受け取る）。ひとりで遊ぶ人には行き止まり。案：社交の段を最後の後ろへ回す、または「どちらか1つ」にする。経済のシミュレーションは全段を受け取る前提なので E1 は動かないはずだが、受け取りの時期がずれるので回してから。
3. **成長の手応えの速さ**：SR の相棒は1日2回の調教で3日目に成長期、充実期は約9日目。1週間に2回段階が上がる方が「育った」が伝わる。段階のしきい値（0/100/350/650/1000‰）は**表示だけ**なので、350→250 にしても経済・ランク戦に影響しない（馬カードと共有ベクターの更新が要る）。
4. **通知の文言**：端末のログボの通知は「今日のログインボーナスを受け取れます」の固定文で、しかも `reminders` は初期オフ。「2日目：繁殖牝馬が届いています」のように中身を言う案（ロック画面の詳細表示の設定に従う）。共有ベクター（C# の通知の予定表）の変更になるので今回は入れていない。
5. **使い道の無い報酬が貯まる**：7日目までにりんごのおやつ・配合素材が7つずつ。調教の画面で「疲れている時におやつ」を提案するなど、使う瞬間を作る（次の候補）。
