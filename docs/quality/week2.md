# 品質パス3：2週目の目標と、持っている物を使う瞬間（8〜14日目）

更新：2026-11-16　ブランチ `quality/week2`（`origin/main` = 0d0960c から）　ログの接頭辞：`q3w2-`
対象：7日目の「明日」・はじめの10歩の社交の段・りんごのおやつと配合素材・成長段階のしきい値。
土台：品質パス1の目標の階段（[goals-rewards.md](goals-rewards.md)）、品質パス2のはじめの1週間（[first-week.md](first-week.md) §5 の決めごと 1・2・3・5）。**新しい仕組みは足さず、階段と既存の報酬表の上に積んだ。無償コインの新しい付与はゼロ（並べ替えだけ）**。

目標：8〜14日目の毎日に「今日開く理由」が1つあり、7日目の時点でそれが見えていること。ひとりで遊ぶ人もはじめの10歩を終えられること。貯まるだけだった物に使う瞬間があること。

- `bash tools/figma-prototype/build.sh` のあと、本物のサーバーの規則（`logic.js`）で、毎日まじめに遊ぶ新規プレイヤーを **14日** 再現した（スクラッチパッドの `q3w2-week.cjs`＝品質パス2の `q2wk-week.cjs` を14日に延ばした物、`q3w2-play.cjs`＝ひとりで遊ぶ人が一歩ずつ行き先の画面でやる版）。日ごとに朝・夜のホームと目標の画面を撮った（`q3w2-before-d{7,8,10,14}-*.png`、`q3w2-after-*`）。
- 1日：ランク戦3本・相棒を2回調教（ミニゲームなし）・まとめて受け取り。

## 9. オーナーに決めてほしいこと

1. **通常ログボの3日目（勝負服の柄「翼」の2個目以降）**：初心者3日目と同じ解放アイテムで、2回目からは何もしない（10日目・17日目…が空の日）。案：通常の表の3日目だけを、持っていれば同じ価値の別の物（例：配合素材×2）に置き換える。**アイテムの付与が増える**ので経済（E15）を見て決める。今回は入れていない。
2. **卒業の日（8日目）**：はじめの10歩を早く終えた人（毎日6戦する人は4日目）は10連券を4日待つ。「最後の段は初心者ログボの後の山」という並べ替えで、崖の日を埋めるのが目的。待つのが嫌なら `fromDay` を外す（設定だけ、remote config で切り替えられる）。
3. **ひとりの道の中身**：フレンド ⇔ おやつ、支部 ⇔ 素材で配合。どちらも「持ち物を使う」練習を兼ねる。別の候補（練習レース・週替わりチャレンジ1つ）も `alt` の種類を足せば設定で替えられる。
4. **2週目の後（15日目〜）**：弧は14日目で終わる。3週目以降は通常の階段（今週・シーズン）。月末の昇級（§68）を次の山として同じ形で出すかは、ランク戦のワークストリームと合わせて。
