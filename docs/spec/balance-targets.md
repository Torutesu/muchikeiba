## 1. プレイヤーのモデル（コードで定義）

| 名前 | 定義（`BalanceHarness.cs`） | 何の代わりか |
|---|---|---|
| 上手い人 `SkilledRider` | ゲートが開いた瞬間にスタート／脚が「残り距離の割合 −100‰」を下回った時だけ手綱／前に馬がいない時は風よけを探して内へ、遅い馬に詰まったら外へ／ムチ6発を最後に使い切るよう間隔20tickで残り約150mから | 操作を理解したプレイヤー |
| 初心者 `CasualRider` | スタートは0〜8tick遅れ（約半分が好スタートを逃す）／手綱で脚を温存しない／ムチは残り250〜600mのどこかから不規則な間隔で／かかった時・詰まった時は半分の確率で遅れて反応／内外の選択は騎手まかせ（自動で内へ） | 始めたばかりのプレイヤー |
| CPU（レベル1〜5） | エンジン内の `CpuBrain`。1.1からレベル1〜3は初心者と同じ癖で走る（`cpuSloppyMaxLevel`） | 対戦相手の穴埋め |

「上手い人」の乗り方は、候補を総当たりして（`rider-sweep`）一番成績の良い組み合わせにした。手綱を早く引きすぎるとむしろ遅く、ムチは残り400mからより最後の150mに集めた方が速い。

### 目標の理由

- **R1 レース時間**：1レース約90秒（企画どおり）。
- **R2 脚質**：どの馬場でも、どの脚質を選んでも「勝ち筋がある」こと。1.0.0では外を回る損が大きすぎて、ダートと芝の硬い馬場で逃げが強すぎた。
- **R3 腕の差**：「腕で勝つ」が柱。上手い人は同じ馬で平均2着ぶん上がり、5%弱い馬でも初心者に8割勝つ。ただし同じ腕なら5%強い馬に3割は勝てる（運と調子の余地を残す）。1.0.0は上手い人が初心者にほぼ100%勝ち、結果が決まりすぎていた。
- **R3c・R5 CPUのレベル**：レベル3は「初心者と同じくらい」。初心者がCPU（レベル3）に負けても平均1着差以内。
- **R4 ムチ**：連打と早打ちは損、間隔をあけて最後に使うのが得。「残り400mから打ち始める」程度の普通の使い方もムチなしより速い（打って損をする体験を作らない）。
- **R6 得意馬場**：得意な馬場では有利だが、勝率が一様の2倍を超えるほど支配的にはしない。
- **R7 枠順**：内枠有利は小さく（4pt以内）。1.0.0は外枠の勝率が内枠の4分の1で、枠順でほぼ決まっていた。
- **R8 能力**：能力は効くが、一番強い馬の勝率は5割未満。

### 1.2.0 で変えたもの（脚質の距離による偏り）

**原因**：スタミナの量とスパート区間（700m）が距離によらず一定だった。消耗はほぼ「速さ²×時間」なので、2400mでは全馬がスタミナ不足になり、風よけ（−30%）と位置取りの手綱（−55%）で消耗を抑えられない逃げだけが先にガス欠になる（スパート開始時のスタミナが他の脚質より低く、根性の下限まで落ちる）。逆に1200〜1600mではスタミナが余るので、後ろで脚をためる得がなく、先頭で楽に運ぶ逃げが一方的に有利だった。

| 芝・良（CPUレベル3、各300レース、`balance … tracks=… track=…`） | スパート開始時の残りスタミナ 逃げ / 先行 / 差し / 追込 | スタミナ0でゴールした馬 |
|---|---|---|
| 1.1.0 ベルムーア1200 | 748‰ / 805‰ / 808‰ / 836‰ | 0% |
| 1.1.0 きらめき2000 | 334‰ / 485‰ / 496‰ / 547‰ | 41% |
| 1.1.0 みなと2400 | 133‰ / 322‰ / 338‰ / 399‰ | 73% |
| 1.2.0 ベルムーア1200 | 331‰ / 479‰ / 491‰ / 550‰ | 41% |
| 1.2.0 みなと2400 | 331‰ / 482‰ / 494‰ / 543‰ | 42% |
馬場（going）の影響は小さく、コースの形もほぼ効かない（下の表の「4馬場の最小〜最大」と旧表）。

**直し方**：新しい任意キー群（**キーが無い1.1.x 以前のリプレイ・ゴーストは今までどおりの結果で検証できる**）で、スタミナの量とスパート区間の長さを距離に比例させた。どの距離でも「1mあたりに使うスタミナの割合」と「スパート区間がレースに占める割合」が2000m芝と同じになり、脚質の釣り合いが距離で変わらなくなる。CPUの脚質ごとの位置取りは変えていない。

| キー | 値 | 中身 |
|---|---|---|
| distanceRefM | 2000 | 芝の基準距離。この距離ではスタミナもスパート区間も1.1.0と同じ |
| distanceRefDirtM | 1850 | ダートの基準距離。ダートは消耗が1割多いので、同じ釣り合いが短い距離にある（1800では逃げが少し強く、1900では弱い） |
| staminaDistanceScalePermille | 1000 | スタミナ量 ×（1 + 1.0 ×（距離−基準）/基準）。1200m芝で0.6倍、2400m芝で1.2倍 |
| spurtDistanceScalePermille | 1000 | スパート区間 = 700m × 同じ係数。1200m芝で420m、2400m芝で840m |

試した値（`harness-tracks` の脚質別勝率、良馬場）：スタミナだけ比例させると芝は直るがダート（基準2000m）で逃げが2〜4%に落ちた → ダートの基準を別にした。比例の度合いを下げる（スタミナ 800〜900‰）と短距離で逃げ12〜15%・2400mで逃げ5%に戻り、スパートだけ800‰にすると1200mで逃げ5.6%と短距離の差しが強くなる。両方1000‰が全コース・全馬場で最も一様に近い。

その他の目標への影響：2000m芝の値は変わらないので R1・R3〜R8 は同じ値。短いコースは消耗の割合が2000mと同じになった分、時計が遅くなる（ベルムーア芝1200は1000mあたり45.3→47.8秒で、目標の48秒の上限に近い。長距離は少し速くなる）。タイムアタックのメダルは全コース計算し直した（下の3章）。

ルールセットの値が変わると結果ハッシュが変わるので `rulesetVersion` を **1.2.0** に上げ、1.1.0 のゴールデンを `contracts/golden/legacy/*.ruleset-1.1.0.json` に残した（今も同じ結果で検証できることをテストしている）。
