# ムチ一閃 / Frontend prototype

競馬ジョッキーゲームの横画面 UI プロトタイプ。グリーン・アイボリー・ゴールド、明朝見出し、オリジナル SVG イラストで構成。縦画面ではレイアウトを積み替えます。

## 起動

Node 24 を使用。

```sh
cd /workspace/muchikeiba/frontend
npm ci
npm run dev
```

`npm run build` で `dist/` に静的サイトを生成。API・Unity・決済への接続はありません。命名のみブラウザの localStorage に保存。通貨、抽選、レース、報酬は固定のデモです。

## Figma で見る

`design/screens.svg` を Figma のキャンバスへドラッグすると全10画面を取り込めます。個別に扱う場合は `design/screens/01.svg` 〜 `10.svg` を読み込み、フレームに変換してください。文字・図形はベクター要素です。Figma の自動レイアウト、コンポーネント、プロトタイプ接続は含みません。SVG は DOM から近似変換したものなので、改行・装飾の正確な参照には同名 PNG を使用してください。日本語フォントは利用環境によって変わります。

Figma への直接投稿は未実施です。画面上部からも一覧 SVG をダウンロードできます。

## 画面と導線

01 規約同意・開始 → 02 最後の直線チュートリアル（仕掛けるを4回）→ 03 相棒の命名 → 04 初回無料スカウト → 05 ホーム。

05 ホーム → 06 厩舎（出走馬選択）→ 07 出走登録 → 08 レース → 09 結果 → 05 ホーム。

10 ショップ → 年齢確認モーダル。ほかにミッション・配合開放案内・フレンドルーム・スカウト説明モーダル。

画面上部のセレクトから任意画面へ移動可能。スクリーン番号と URL ハッシュは 0 始まりです。

## 検証

`npm run build` 成功。ブラウザで開始からホームまでを操作し、10画面を巡回。390px幅の横はみ出し・JavaScriptエラーなし。

`scripts/export-design.cjs` は Playwright と `/usr/bin/chromium` がある本クラウド環境向けの書き出し兼導線確認ツール。開発サーバーを起動してから `node scripts/export-design.cjs` を実行。Playwright はアプリ依存関係には含めていません。
