# ムチ一閃 — The Racing Club / Design Edition 02

## デザインの基準

「上質な競馬クラブ」を共通の基準にする。静かなクラブ画面と、緊張感のあるレース画面を、同じ色・書体・操作部品でつなぐ。

| 役割 | 色 | 使い方 |
| --- | --- | --- |
| Forest | `#142F27` | ナビゲーション、主ボタン、メインビジュアル |
| Ivory | `#F7F6F0` | 画面全体、モーダル |
| Panel | `#FFFEFA` | カード、入力面 |
| Ink | `#213A32` | 見出し、重要な情報 |
| Gold | `#B39459` | 記章、レアリティ、装飾の細線 |
| Gold light | `#E2C88E` | 暗い面の見出し、主導線の強調 |
| Line | `#DEDFD3` | 区切り、カードの境界 |
| Error | `#B04B3C` | 入力エラー。通常の強調には使わない |

色の参照先は `src/style.css` の CSS 変数。明朝の Club Serif は見出し、Club Sans は本文・操作、Georgia はタイムやコレクション番号に使う。Club Sans / Serif は Noto CJK の必要字形を抽出・改名したフォントで、ライセンスと Figma 用 OTF を同梱する。

デスクトップは同じサイドナビ・ヘッダー・本文幅を全画面で使う。モバイルは下部ナビへ切り替え、二列の情報を一列へ積む。主ボタンと副ボタン、入力、タブ、選択中、受取済み、空、エラー、確認完了を同じ規則で描く。英字は装飾上の補助とし、操作は日本語で示す。

## モデルとアート

`frontend/scripts/build-showroom.py` は既存の Blender ソースを基に、連続した胴体・首・脚、肩の接続、つながった繋部、顔の比率、たてがみ、馬具を再構成する。毛色と斑点・白斑は頂点カラーへ置き換え、古い立体の粒や白い球体の表現を使わない。

鹿毛・栗毛・芦毛の3種類を GLB へ書き出す。各 GLB にスキンと `Gallop_Loop` があり、ブラウザで骨格を動かす。静止画も同じモデルから Cycles で生成するため、カードと3Dの色・形を揃えられる。レースでは芝・レール・影を Three.js 側で描画する。

これはブラウザ用のモデル更新。既存の Unity FBX・Unity の画面・別の `tools/figma-prototype` を自動的に置き換えるものではない。レース操作は従来のローカル画面デモで、競走結果はエンジンへ接続していない。

## 表示・性能・動き

- 3D のコードと GLB は必要な時に読み込む。
- モデルはブラウザ用にポリゴンを削減し、材質ごとに結合する。
- 静止画は WebP、フォントは必要な字形に絞る。
- 3D は描画間隔を抑え、画面を閉じたらカメラ操作・監視・描画・GPU資源を解放する。
- `prefers-reduced-motion` では自動回転・走行を止め、手動の回転は残す。
- WebGL が使えない場合は静止画へ戻し、画面操作は維持する。

## Figma と確認

基本10画面と詳細・入力状態・確認・モバイル・3Dの30種類を `screens/` へ生成する。画像・3Dキャプチャは SVG 内へ埋め込む。書体を揃える場合は `fonts/` の OTF を使う。

SVG はブラウザ DOM の近似変換で、CSS の影やクリッピング、疑似要素などに差が残る。同名 PNG が実際のブラウザ表示の参照。Auto Layout・再利用コンポーネント・Figma のプロトタイプ接続は含まない。3D の操作・アニメーションはブラウザ版で確認する。

## Creative素材の画面内展開

厩舎の検索結果なし・配合未開放には、それぞれの状態を表すイラストを使う。馬詳細にはモデルごとの勝負服と共通ゼッケンを添え、装備変更とは区別する。リザルトの報酬内訳には透過トロフィーと無償コインの合計を配置する。ショップの通貨画像はラベルと併用し、有償コインの数量・価格を常に文字で残す。

シーズンの「コレクションを見る」から3色の勝負服を比較できる。選択はダイアログ内のプレビューに限り、`aria-pressed` と状態文言の両方で示す。画像だけに操作を持たせず、カード全体をボタンとする。390pxでも横方向のスクロールを発生させない。
