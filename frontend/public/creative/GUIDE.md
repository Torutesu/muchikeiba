# ムチ一閃 / Creative Atelier 01

「上質な競馬クラブ」を、絵・ロゴ・状態・動き・音・材質まで揃えるための素材セットです。`index.html` で検索・絞り込み・仕様確認・試聴・動きの再生ができます。サーバー上では `/creative/index.html`、配布ZIPでは解凍後の `index.html` を開きます。

## 内容

| 種類 | 数 | 形式・内容 |

| 背景・オブジェクト | 4 | 夜明けの厩舎、スカウトのゲート、シーズン衣装、透過トロフィー |
| ブランド | 5 | クラブ章2色、横組みロゴ2色、不透明1024pxアプリアイコン |

## 共通の判断

- 深いフォレスト `#142F27`、アイボリー `#F7F6F0`、ブラス `#B39459`。派手な虹色・ネオン・カジノ風の演出を足さない。
- 見出しは Club Serif、本文と操作は Club Sans。ロゴ原版はアウトライン。フォントとOFL文書を `fonts/` に同梱。
- 写真的な背景は文字を焼き込まない。価格、数量、名前、提供条件、取得条件、開催期間はUIで管理する。
- 色だけで有償/無償・選択/未選択を伝えず、ラベルやチェックも添える。
- PNGの透明部分は維持する。SVGをアイコンとしてインライン化する時は `currentColor` を使う。
- UIの枠、絵、文言、クリック領域を別レイヤーにする。装飾をボタンのタップ領域にしない。

## 背景の文字エリア

`safeArea` は原版に対する `[左, 上, 右, 下]` の比率です。実測値はWebP書き出し後の範囲内で、アイボリー文字 `#F7F6F0` と最も明るい画素との比です。

| ID | safeArea | 最小コントラスト比 |
| --- | --- | ---: |
| greenfield-dawn | .04 / .10 / .42 / .90 | 6.60 : 1 |
| scout-gate | .04 / .12 / .34 / .84 | 12.91 : 1 |
| season-collection | .04 / .12 / .32 / .82 | 14.25 : 1 |

比率は文字が置ける領域の目安で、画像全域に文字を置けるという意味ではありません。トリミングする場合はこの矩形も変換します。ゴールドの小文字や別の文字色を使う場合は、暗いオーバーレイを含めた表示で確認してください。透過トロフィーは切り抜きオブジェクトで、背景用の文字エリアはありません。

## ロゴとクラス

横組みロゴは最小180px幅、クラブ章は32px以上を目安にします。周囲にクラブ章幅の1/4程度の余白を確保し、縦横を別々に伸ばさないでください。

クラス章は `server/master/progression.json` の `C / B / A / S` を識別子にしています。旧ブラウザデモの「ブロンズII」などの仮の表示名を章へ焼き込まず、接続先のクラス表示名と組み合わせます。章の見た目から昇級条件や報酬を新設するものではありません。

## 枠・アイコン・アトラス

カード原版は320×420px。装飾を壊さず可変サイズへ使うため、Rは32px、SRは38px、SSRは44pxを9-sliceの保護幅にします。`frames/frames.css` の絶対配置用オーバーレイを使えます。内容のラベルも保護幅の内側に配置します。選択中・未開放の画像は別レイヤーで、固定比率を維持します。可変比率のUIではチェックやロックを別のアイコンとして配置する方法も使えます。

```html
<link rel="stylesheet" href="/creative/frames/frames.css">
<div style="position:relative;min-width:240px">
  <!-- 写真、能力、ローカライズした文字など -->
  <span class="mi-card-frame mi-frame-ssr" aria-hidden="true"></span>
</div>
```

Figma向けには `figma/icons/` に固定色のSVGも同梱しています。Web向けの `icons/` は `currentColor` のまま使えます。

`atlas/ui-icons@2x.png` は1024×640pxの白いアルファマスク。128pxのセルに64pxの切り出し領域と32pxの余白を設けています。`ui-icons.json` は左上原点、`ui-icons-unity.json` は左下原点です。Unity用の推奨Importer設定もJSONに記録しています。PNGをSprite Multipleとして使い、色はUI側で付けます。外部SVG対応がない環境でもPNGを使えます。

パターンはシームレスな64pxタイルです。SVG内部にも薄い色があるため、合成のレイヤー不透明度は0.3程度から調整してください。通常の説明文の直下には使いません。

## 空状態と文言

状態の絵には文章を入れていません。`copy.json` に日本語・英語の短い案内を分けています。通信失敗や未開放を、レースでの失敗・馬の能力不足と混同しない文言にします。案内の後には、検索条件のクリア・再試行・開放条件の確認など、その状態でできる行動をUI側に置きます。

### 状態ごとの置き方

- 検索なし：地図と虫眼鏡。条件のクリアを近くに置く。
- 空の厩舎：空の扉。新しい相棒へ進む導線と組み合わせる。
- 配合未開放：血統と鍵。一般的な操作エラーに見せない。
- 通信：再試行を案内し、入力や選択を失ったように見せない。
- 受取完了：開いたギフトとチェック。再受取の主ボタンを置かない。
- 準備中：厩舎と時計。復旧時刻を画像に焼き込まない。
- 操作エラー：全体の処理を完了できない時の小さな注意。名前の文字数などの入力エラーは、この大きな絵を出さずフィールド内の案内を優先する。

## 動きと音

`motion/motion.json` の時間とイージングを使います。パネル220ms、カード260ms、押下90ms、選択160ms、報酬420ms、案内180ms、勝利480ms、読込1100ms。読込以外は原則1回で終えます。

```js
import {playMotion} from '/creative/motion/motion.js';
const stop = playMotion(visualWrapper, 'reward');
// 読込ループは完了時に stop() を呼ぶ。
```

フォーカス可能なボタン自体を動かさず、内側の見た目のラッパーに適用します。`prefers-reduced-motion` では静止に切り替えます。読込は動きを止めてもラベルや aria-busy による状態の案内を残します。スカウト10枚の開示は、カードごとの遅延35ms程度を目安にし、長い待ち時間を作りません。

音は録音素材ではなく、このセット用の合成音です。ピークは約−7.96dBFS、推奨再生音量は0.18、初期ミュート。`audio/mix.json` は接続用の初期値です。素材カタログでは明示的な操作時のみ試聴し、ゲームへの自動再生は接続していません。ホバーや一文字ごとの入力では鳴らさず、確定操作に結び付けます。エラー音は短く穏やかにし、報酬音と混同しません。

## PBR材質と告知テンプレート

`materials/club-materials.blend` には17材質がAssetとして入っています。AppendまたはAsset Browserで利用できます。JSONの色はsRGB、BlenderのBase Colorへはリニアに変換しています。SVGの球は模式プレビューで、実際の見え方は照明と形状にも依存します。織り・毛のノーマル参照は、GLBへ持ち込む場合にベイクする前提です。既存のUnity FBXやGLBを自動変更しません。

告知・シェア用の正本SVGは画像埋め込みと文字アウトライン。`templates/source/` は文字を編集できるSVGです。Figmaで書体を揃える時は同梱OTFをインストールします。`bindings.json` に差し替え用の例を記録しています。戦績の名前・順位・タイムは作例なので、投稿・公開時には確定した結果に置き換えます。相棒名は最大12文字を想定し、610px幅に収まるよう56pxから最小36pxまで縮小します。省略で名前の一部を消さない方針です。日本語・英語の告知コピーは `copy.json` に分け、言語によって行数と字数が変わる前提で組みます。

## 原版・再生成

PNG原版4点と生成プロンプトは `masters/` と `provenance.json`。生成ツールは `image_gen`、その他のSVG・レイアウト・合成音・PBR設定はリポジトリ内の制作スクリプトです。フォントの出典とライセンスは `fonts/LICENSE.txt`。原版を上書きせず、WebP・PNG書き出しを派生物として扱います。

リポジトリのルートで実行します。通常のアプリ起動には再生成は不要です。

```sh
python3 frontend/scripts/build-creative.py
blender -b --factory-startup --python-exit-code 1 --python frontend/scripts/build-creative-materials.py
# 開発サーバーを5173で起動してから
node frontend/scripts/render-creative.cjs
node frontend/scripts/verify-creative.cjs
python3 frontend/scripts/package-creative.py
```

Pillow・fontTools・Blender・Playwright・Chromiumを使います。再生成スクリプトは元のリポジトリ構成で実行するもので、配布キット単体の実行は想定しません。
